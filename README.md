# Atividade Prática de Fixação 3 - Desenvolvimento FrontEnd

Este repositório contém as soluções para a **Atividade prática de fixação - Lista de Exercícios** da disciplina de **Desenvolvimento FrontEnd** do **Universitário Jorge Amado**.

## 🎯 Objetivo da Atividade
O foco principal desta lista de exercícios é a manipulação do DOM (Document Object Model) e a aplicação de eventos dinâmicos, utilizando majoritariamente o método `addEventListener()` para criar interfaces interativas em JavaScript.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização e feedback visual das interações.
* **JavaScript (ES6+):** Lógica de programação, manipulação do DOM e escuta de eventos.

---

## 📋 Projetos e Exercícios Desenvolvidos
Abaixo estão os 20 desafios propostos e resolvidos neste projeto:

1. **Sistema de Login Acadêmico:** Validação de usuário e senha, impedindo o envio de formulários vazios e prevenindo o recarregamento da página.
2. **Controle de Temperatura:** Monitoramento em tempo real onde a tela altera sua cor (verde, amarelo ou vermelho) conforme a temperatura digitada através de eventos de teclado.
3. **Contador de Caracteres:** Sistema para rede social que atualiza dinamicamente os caracteres restantes de um comentário com limite de 200.
4. **Carrinho Eletrônico:** Atualização automática do valor total de uma compra assim que o usuário altera a quantidade do produto.
5. **Força de Senha:** Validação em tempo real (fraca, média, forte) durante a digitação no cadastro de usuários.
6. **Luminosidade Inteligente:** Utilização de um *input range* para simular a alteração na intensidade de cor/luz de uma lâmpada.
7. **Pesquisa de Filmes:** Filtro dinâmico e instantâneo de uma lista de filmes durante a digitação no campo de busca.
8. **Transferência Bancária:** Sistema que requer confirmação de operação, valida saldo mínimo e exibe mensagens de erro ou sucesso na interface.
9. **Dark Mode:** Botão que alterna o tema da página, modificando as cores de fundo, textos e do próprio botão.
10. **Alerta de Estoque:** Emissão automática de alerta caso a quantidade numérica digitada para o estoque fique abaixo de 10 unidades.
11. **Player de Curso EAD:** Gatilho que inicia automaticamente a reprodução do vídeo da aula ao clicar sobre a miniatura.
12. **Avaliação por Estrelas:** Sistema interativo de 5 estrelas com exibição de mensagem correspondente à nota selecionada.
13. **Calculadora IMC:** Cálculo automático do Índice de Massa Corporal logo após o término da digitação dos dados de peso e altura.
14. **Preview de Upload:** Interceptação do campo de arquivo para exibir o nome do documento selecionado na tela antes do envio.
15. **Sistema de Votação:** Contabilização dinâmica e instantânea de votos ao clicar nos candidatos de uma lista.
16. **Notificações em Hover:** Exibição de uma caixa de notificações ativada quando o usuário passa o mouse sobre um ícone.
17. **Semáforo Digital:** Simulador educacional de trânsito que alterna automaticamente entre as cores verde, amarelo e vermelho após a ativação.
18. **Agenda Interativa:** Lista de horários de clínica com aplicação de destaque visual interativo no horário escolhido pelo usuário.
19. **Conversor de Moedas:** Sistema de conversão em tempo real de reais para dólar conforme os valores são digitados.
20. **Mini Player de Áudio:** Painel de controle de música simples integrado com botões de *play*, *pause* e barra de regulagem de volume.

## 🛠️ Como Executar o Projeto

1. Faça o clone deste repositório em sua máquina local:
   ```bash
   git clone [https://github.com/seu-usuario/nome-do-repositorio.git](https://github.com/seu-usuario/nome-do-repositorio.git)
   ```
2. Navegue até a pasta do projeto.
3. Abra os arquivos `.html` referentes a cada questão (ex: `questao01.html`) diretamente no seu navegador de preferência.
4. Teste as interações na tela e acompanhe o comportamento do DOM.
